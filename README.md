# Code Clinic 🩺 — AI Code Review (Ollama Cloud) 

> **Advice-only AI code review** for many languages—no local linters or compilers.
> Paste code → pick a language → get clear findings with **severity levels** and **step-by-step fixes**.
> Built for fast demos and classroom / hackathon environments.

---

## ✨ What’s in this repo

* **AI-only** review via **Ollama Cloud** (e.g., `qwen3-coder:480b-cloud`, `deepseek-*`, etc.).
  ⛔️ *All traditional static analyzers (Checkstyle/ESLint/pylint/clang-tidy…) are removed in this build.*
* Clean React UI with:

  * Severity labels (**critical / high / medium / low / info**)
  * **Filters** to view only the severities you care about
  * “Advice-only” insights (what/why/how-to-fix) — **no patched code**
* Simple Python/Flask backend that proxies requests to Ollama Cloud (keeps your API key server-side)
* **Demo Link:** https://drive.google.com/file/d/1I9T21tavS9VlTAaPbgCV1hWXoHh0kSdZ/view?usp=sharing
---

## ✅ Supported languages

The reviewer is **language-aware** and works well with:

* **Python**, **C++**, **JavaScript**, **Java**, **SQL**, **C#**
* …and generally **most mainstream languages** (the model prompt is guided by the selected language)

> Note: Findings are generated by the model (not a compiler), so line numbers are best-effort when the model can infer them.

## 🚀 Quick Start (Local Dev)

### 1) Backend

```bash
cd backend
python -m venv .venv
# Windows
.\.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
```

Create **`backend/.env`**:

```env
# Required
OLLAMA_HOST=https://ollama.com
OLLAMA_API_KEY=sk_********************************

# Pick any cloud model your account can access:
# Examples: qwen3-coder:480b-cloud, deepseek-v3:671b-cloud, glm-4.6:cloud, ...
OLLAMA_MODEL=qwen3-coder:480b-cloud

# Optional: change Flask port if needed
PORT=8080
```

Run the server:

```bash
python app.py
# Flask listening at http://localhost:8080
```

### 2) Frontend

```bash
cd ../frontend
npm i
```

Create **`frontend/.env`** (or `.env.local`):

```env
VITE_API_BASE=http://localhost:8080
```

Start the UI:

```bash
npm run dev
# Open the URL Vite prints (e.g., http://localhost:5173)
```

## 🧠 How to use

1. Open the app in your browser.
2. Paste code into the editor and **select its language**.
3. Click **AI Review**.
4. Review the **AI Insights**:

   * Each finding has **severity**, optional **line**, a concise **why**, and **fix steps**.
5. Use the **severity filters** to focus on what matters (e.g., show only *critical/high*).

> The app intentionally provides **advice only** and avoids returning patched code.

## 📡 API (Backend)

### `POST /ai_review`

**Request**

```json
{
  "lang": "python",
  "code": "def f(a): return a+u",
  "issues": []              // optional: pass any pre-known issues; not required
}
```

**Response (example)**

```json
{
  "language": "python",
  "model": "qwen3-coder:480b-cloud",
  "insights": {
    "summary": "The function references an undefined variable 'u'.",
    "findings": [
      {
        "title": "Undefined variable 'u'",
        "severity": "high",
        "line": 1,
        "why": "Using an identifier that is not in scope will cause a runtime error.",
        "fix_steps": [
          "Replace 'u' with the intended parameter or variable.",
          "If you meant 'a', compute and return the correct expression.",
          "Add the missing variable or pass it as a parameter."
        ]
      }
    ]
  }
}
```

**Test with curl**

* **PowerShell** (escape quotes carefully):

```powershell
curl.exe -X POST http://localhost:8080/ai_review `
  -H "Content-Type: application/json" `
  -d "{""lang"":""python"",""code"":""def f(a): return a+u"",""issues"":[]}"
```

* **bash / zsh**

```bash
curl -X POST http://localhost:8080/ai_review \
  -H "Content-Type: application/json" \
  -d '{"lang":"python","code":"def f(a): return a+u","issues":[]}'
```

## 🔐 Security & privacy

* Keep your **OLLAMA_API_KEY** on the **server only** (this repo uses a backend proxy for that).
* Don’t commit `.env` files.
* For production, lock down **CORS** to your frontend origin.
* The app doesn’t store code; it’s sent to the model and the response is rendered.

---

## 🌐 Deployment notes

* **Backend**: Any Python host (Render, Railway, Fly.io, AWS, etc.).

  * Set environment variables (not files).
  * Expose the Flask port you choose (`PORT`).
  * Add CORS if your frontend is on a different origin.
* **Frontend**: Any static host (Vercel, Netlify, Cloudflare Pages).

  * Set `VITE_API_BASE` to your deployed backend URL.
  * Rebuild after changing envs.

## 🧪 Troubleshooting

* **No AI card shows up**

  * Check DevTools → **Network**: Does `POST /ai_review` return **200**?
  * Check the backend console for request logs.
* **401 Unauthorized**

  * Invalid/missing `OLLAMA_API_KEY` or expired token.
* **Model not found**

  * Your `OLLAMA_MODEL` must match a tag your account can access (see `/api/tags`).
* **CORS blocked**

  * Enable CORS in Flask for your frontend origin:

    ```python
    from flask_cors import CORS
    CORS(app, resources={r"/*": {"origins": "*"}})  # loosen for dev only
    ```
* **Mixed content**

  * If your frontend is `https://`, your backend should also be HTTPS.
